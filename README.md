# Nícolas Silva — Software & AI

An English-language portfolio built with **React 19, TypeScript and Vite**. Black and red visual identity, a procedural animated network, project filters and accessible native project dialogs, an interactive architecture explorer, a simulated workflow trace, sensor-chart controls, mobile navigation and a saved motion preference.

## Development

```sh
npm ci
npm run dev
npm run build
npm run preview
```

`npm run build` runs TypeScript checking before creating `dist/`. Hosting configuration is in `.openai/hosting.json`.

The site is a client-only frontend. No credentials, live LLM requests, customer data or backend are required. If a backend is added, the requested framework is **FastAPI**. Flask mentioned in the To-Do project is a technology of that existing portfolio project, not a backend for this site.
